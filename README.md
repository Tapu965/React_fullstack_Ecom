# React Course Projects

This repository contains four projects and exercises created while learning React and full-stack development.

## Projects

| Folder | Description | How to run |
| --- | --- | --- |
| [`chatbot-project`](./chatbot-project/) | A React chatbot application built with Vite. | `cd chatbot-project`, `npm install`, then `npm run dev`. |
| [`ecommerce-project`](./ecommerce-project/) | A React e-commerce storefront built with Vite. | `cd ecommerce-project`, `npm install`, then `npm run dev`. |
| [`ecommerce-backend`](./ecommerce-backend/) | Express API backend for the e-commerce project. | `cd ecommerce-backend`, `npm install`, then `npm run dev`. |
| [`react-basic`](./react-basic/) | Introductory React examples using standalone HTML and JavaScript files. | Open `react-basic.html` or `chatbot.html` in a browser. |

## Requirements

- Node.js and npm for the Vite applications and backend.
- A modern browser for the React basics examples.

## Getting started

Clone the repository:

```bash
git clone https://github.com/Tapu965/React_fullstack_Ecom.git
cd React_fullstack_Ecom
```

Each Node.js project has its own dependencies. Install them from that project's folder before running it. Run the e-commerce backend and storefront in separate terminals when working with the full-stack application.

The Vite projects also provide these scripts:

```bash
npm run build
npm run lint
```

Run those commands from the relevant project folder. The backend's development command uses Nodemon; its `start` script runs the server directly with Node.js.
